# 🎫 Ticket Open Schedule Bot

매주 일요일/수요일, NOL 티켓 / 멜론티켓 등에서 다음 주 예매 오픈 예정 공연을 수집해 Notion으로 전송합니다.

NOL 티켓은 `crawler/nol.py`의 `NolCrawler`를 사용합니다. 오픈 예정 목록 API의 모든 페이지를 조회하고, 공지에 포함된 선예매·일반예매 일정을 각각 기간 필터링합니다. 공연정보와 출연진도 같은 API 응답에서 추출하며, 상세 링크는 `https://nol.yanolja.com/ticket/products/{goods_code}`입니다. 기존 `crawler/interpark.py`와 설정은 보존되어 있습니다.

## ✅ 기능
- LG아트센터는 기본 공지 페이지에서 ‘티켓’ 버튼과 동일한 필터 요청으로 매번 조회 주소를 생성하고, 티켓 분류 1페이지의 상세 공연정보만 수집합니다. 고정된 `q` 값에 의존하지 않으며 다음 페이지는 조회하지 않습니다. 예매 오픈 일시에 기존 기간 필터를 적용합니다.
- 매주 일요일/수요일 08:00 자동 실행 (GitHub Actions)
- 놀티켓, 멜론티켓, 세종문화회관 티켓, 예술의 전당 티켓 예매 오픈 예정 공연 수집
- 공연명, 예매시작일시, 공연기간, 예매처, 출연진 포함
- Notion 페이지에 자동 전송

## 멜론 423 차단 처리
- 목록 요청에서 423이 발생하면 멜론의 나머지 페이지·장르·상세 요청을 즉시 중단합니다. 정상 응답이면 기존처럼 모든 설정 페이지를 수집합니다.
- 다른 예매처는 계속 수집해 Notion에 저장합니다.
- GitHub Actions는 차단이 감지된 경우 1시간 대기한 후 전체 수집을 1회 재실행합니다. 예매처 간 병합 정보를 유지하기 위해 전체 수집을 다시 수행합니다.
- 재실행에서도 차단되면 수집된 결과와 iCal 파일을 저장한 뒤 워크플로우를 실패로 표시합니다. 추가 자동 재시도는 하지 않습니다.
- 로컬 실행은 차단 상태만 기록하며 자동 재실행하지 않습니다. Actions의 1시간 대기는 실행 중인 러너 시간을 사용합니다.

## Notion 요청 제한 처리
`notion-client==3.1.0`과 Notion API `2025-09-03`을 사용합니다. 로컬 환경도 `python -m pip install -r requirements.txt`로 동일한 버전을 설치합니다. SDK 자동 재시도는 `retry=False`로 끄고 아래 공통 게이트가 관리합니다. 데이터베이스 ID를 데이터 소스 ID로 변환한 뒤 `data_sources.query`를 사용합니다.

Notion API 요청은 프로세스 내 공통 게이트에서 최소 0.5초 간격으로 실행합니다.
429(요청 제한) 또는 529(서버 과부하) 응답이면 `Retry-After` 이상 대기하고, 지수 백오프와 작은 무작위 지연을 더해 최대 3회 시도합니다.
대기 중에는 다른 티켓의 Notion 요청도 멈춥니다. 여러 프로세스나 워크플로우에서 같은 연결을 동시에 사용하면 합산 요청량으로 제한될 수 있습니다.

기존 티켓은 수집 대상의 오픈 일시 범위로 한 번 조회하며, 결과가 많으면 100건씩 페이지네이션합니다. 제목과 오픈 일시로 매칭하여 티켓마다 검색하지 않습니다. 조회 실패 시 쓰기를 시작하지 않아 중복 생성을 방지합니다.

속성은 값이 달라진 필드만 수정하고, 본문은 현재 블록을 조회해 변경된 블록만 갱신합니다. 블록 종류나 길이가 바뀌면 필요한 뒷부분을 교체합니다. 내용이 같으면 Notion 쓰기는 생략하지만 본문 확인용 읽기와 iCal 파일 생성은 수행합니다. 배우·작품 관계 갱신도 기존 값이 같으면 생략합니다.

`ticket_schedule.yml`과 `follow_update.yml`은 동일한 `notion-ticket-schedule` concurrency 그룹을 사용합니다. 브랜치나 워크플로우 종류와 관계없이 저장소 안에서 한 실행만 진행하며, 실행 중인 작업을 취소하지 않고 후속 실행을 대기시킵니다(최대 100개 대기). 멜론 재시도 대기 1시간 동안에도 그룹을 유지합니다. 로컬 실행이나 다른 저장소의 실행까지 잠그지는 않습니다.

## 🔐 환경변수

- `NOTION_TOKEN` – Notion Integration 토큰
- `NOTION_PAGE_ID` – Notion Page ID
- `NOTION_DB_ID` - Notion database ID
- `NOTION_ACT_DB_ID` -  Notion follow 배우 database ID
- `NOTION_TITLE_DB_ID` - Notion follow 작품 database ID
- `GB_ICAL_DIR` - 공연 일정 iCal 파일 저장 디렉토리
- `GB_ICAL_URL` - 공연 일정 iCal 파일 URL
- `GB_BRANCH` - GitHub Branch 이름
